# Modèles Android Meshy

Ce dossier est réservé aux modèles GLB optimisés pour la version Android de Clandestin, Arcade Manager.

Fichiers prévus :
- `arcade-cabinet.glb` — borne d’arcade Android
- `slot-machine.glb` — machine à sous Android
- `roulette-machine.glb` — roulette Android

Ces modèles sont séparés des assets PC haute qualité afin de garder l’APK plus léger. Le moteur doit privilégier ces fichiers sur Android et conserver les modèles desktop sur PC.
